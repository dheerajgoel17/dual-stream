Dual Stream

Watch up to 9 videos side by side in one Chrome tab.

Install (unpacked)

  1. Download: ZIP from GitHub
  2. Unzip the folder
  3. Open chrome://extensions
  4. Enable Developer mode
  5. Click Load unpacked and select the project folder
View on GitHub

Usage

Pin the extension, click Open multi-view, or press Alt+Shift+S. See USAGE.md.
